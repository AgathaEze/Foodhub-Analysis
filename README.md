# Foodhub-Analysis
## Project overview
Foodhub is a food aggregator company that offers access to multiple restaurants through a single smartphone app.

The analysis offers insights into customer behavior, restaurant performance, cuisine preferences and order patterns across the week, delivery times, and customer satisfaction through ratings. 

## Tools
* Excel- Data cleaning and Data Visualization

## Tasks Performed
* Data loading and inspection.
* Data Cleaning and formatting.
* Adding calculated columns.
* Designing an interactive report.
